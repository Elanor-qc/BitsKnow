# SPEC-03: 模块与对话界面

## 目标
模块列表页 + 模块内聊天页（流式显示），打通「新建模块 → 对话 → 持久化」闭环。

## 内容
1. 对话 tab（首页）：
   - 模块列表卡片：标题、最近消息摘要一行、updatedAt；点进模块
   - 新建：对话框输入标题即建（无表单、无 Mission）
   - 长按/滑动删除模块（连带消息与卡片级联删除，二次确认）
2. 聊天页：
   - 消息列表（LazyColumn，用户右侧/助手左侧气泡），进入时加载历史
   - 底部输入框 + 发送；发送时立即落库 user 消息
   - AI 回复流式追加渲染，完成后落库 assistant 消息
   - 发送中禁用输入、可「停止生成」（取消 OkHttp call）
   - 出错时消息位显示错误 + 重试按钮
   - 返回时更新模块 updatedAt
3. 首条消息发送前注入教学系统 prompt（见 SPEC-05 定义 system prompt）

## 验收
模拟器实测：新建模块→对话→退出重进历史完整；杀进程后数据仍在。
